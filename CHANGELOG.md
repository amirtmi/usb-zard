# Changelog / تغییرات

## 2.0.0

- Renamed the application to usb zard and added its logo/Windows icon.
- Added RAW-filesystem recognition, native writable queries and first-block observations.
- Preserved unknown partition attributes.
- Blocked inappropriate RAW CHKDSK/file tests and repeated clearing of absent locks.
- Added bilingual error explanations, retained findings and small SHA-256 file verification.
- Added guarded DiskPart script fallback and stronger format-result verification.
- Avoided long Windows command lines through a structured stdin protocol.

نام برنامه به usb zard تغییر کرد و لوگو و آیکن اضافه شد. تشخیص RAW، پرس‌وجوی بومی، حفظ ویژگی‌های نامشخص، جلوگیری از عملیات نامناسب، توضیح خطاها، آزمون کوچک فایل و بررسی دقیق‌تر نتیجه فرمت افزوده شدند.

## 1.0.0

Initial Windows WPF diagnostic and explicitly confirmed storage-operation implementation.

نسخه اولیه تشخیص WPF ویندوز و عملیات ذخیره‌سازی با تأیید صریح.
